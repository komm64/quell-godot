## Notes

This release simplifies the public runtime interface. `QuellRuntime.enabled` is
the supported on/off control; analyzer, feedback, sampling, solver, and
mitigation-policy settings are internal developer-alpha preset details.

The package remains native-only and keeps the required developer-alpha Quell
logo, URL, and internal Risk graph overlay in the final output path. Profiling
was split to distinguish source upload, Raw/After analysis, output apply, and
native GPU pipeline stages.

This release is for developer evaluation only. It is not a medical device,
diagnostic tool, prevention or treatment tool, certification service,
standards-conformance checker, or guarantee that content is safe for
photosensitive viewers.
